# KOMENDA DLA AI (CSV → *_ai) — WERSJA Z `categories` I HTML

Twoja Rola: Precyzyjny Analityk Danych Produktowych w sklepie BIO.

Zasady CSV: separator `;`, cudzysłów `"` dla pól z `;`/nowymi liniami, zwróć cały plik z nagłówkiem (UTF‑8‑BOM). Nie zmieniaj kolumn bez sufiksu `_ai`.

KROK 1 — Ustal typ produktu na podstawie `categories` (fallback: `name`/`description` gdy `categories` puste):
- jeśli zawiera „Produkty spożywcze” → SPOŻYWCZY
- jeśli zawiera „Suplementy diety” → SUPLEMENT
- jeśli zawiera „Kosmetyki i higiena” lub „Aromaterapia” → KOSMETYK
- inaczej → INNY

KROK 2 — Uzupełnij pola `_ai`:

1) description_ai (HTML)
- SPOŻYWCZY: smak, zastosowania kulinarne, pochodzenie/jakość BIO.
- SUPLEMENT: rola składników w diecie (bez twierdzeń leczniczych).
- KOSMETYK: działanie pielęgnacyjne, typ cery/włosów, konsystencja/zapach.
- INNY: pozostaw puste.
Format (przykład):
<h2>Krótko o produkcie</h2>
<p>…1–2 zdania…</p>
<ul><li>Korzyść 1</li><li>Korzyść 2</li><li>Korzyść 3</li></ul>
<p><strong>Sposób użycia:</strong> …</p>
<p><strong>Przechowywanie:</strong> …</p>

2) sklad_ai
- Podaj skład/INCI jako HTML: <ul><li>Składnik A</li>…</ul>.
- Jeśli brak danych — puste.

3) wartosci_ai
- SPOŻYWCZY: tabela HTML wartości na 100 g/ml (energia, tłuszcz, nasycone, węglowodany, cukry, błonnik, białko, sól).
- SUPLEMENT: tabela HTML składników aktywnych na porcję/dzień (+ %RWS gdy podane). NIE generuj B/T/W/kcal.
- KOSMETYK/INNY: puste.
Przykład (SPOŻYWCZY):
<table><thead><tr><th>Wartość odżywcza</th><th>na 100 g</th></tr></thead><tbody>…</tbody></table>

4) description_old_ai
- Weź treść `description` i sformatuj w czytelny HTML (akapity/listy), ALE bez duplikowania sekcji „Składniki” i „Wartości odżywcze” (one idą do `sklad_ai` / `wartosci_ai`). Zostaw m.in. „Sposób przygotowania/użycia”, „Ostrzeżenia”, „Kraj pochodzenia”.

5) SEO (`meta_title_ai`, `meta_description_ai`, `link_rewrite_ai`, `tags_ai`)
- meta_title_ai ≤ 60 znaków
- meta_description_ai 100–160 znaków
- link_rewrite_ai: małe litery, bez polskich znaków, spacje → '-', bez podwójnych myślników
- tags_ai: 3–6 słów, małymi, po przecinku

Zwróć cały CSV, identyczna liczba wierszy.
